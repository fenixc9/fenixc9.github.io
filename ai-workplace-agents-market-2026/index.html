AI 办公 Agent 调研：市场格局、模型选择与差异化策略

AI 办公产品正在从对话和内容生成，扩展到跨文件、跨应用的任务执行。员工可以让 Agent 研究资料、制作报告、更新知识库，或在已有业务系统中处理工作流程。

本文对比七类主流产品的公开使用规模、可用模型和差异化策略。重点是理解各家如何获得用户、接入工作数据和完成任务。

资料核对日期：2026 年 10 月 29 日。范围为全球通用办公与企业工作流，未覆盖中国办公产品。文中的产品策略和选型建议是基于公开资料的分析，未进行独立产品实测。模型、功能和开放范围可能随版本、地区及套餐变化。

先区分市场指标

公开资料尚不足以制作一份可信的全球办公 Agent 市场份额与日活排行榜。厂商通常披露整个产品的周活或月活、企业付费席位、客户数或收入。第三方调查还会统计企业是否批准使用某个产品。这些指标的分母和时间范围不同。

指标 衡量什么 不能直接说明什么
企业渗透率 样本企业中采用或批准某产品的比例 员工实际使用频率；多产品比例也不能相加
周活或月活 某周期内使用产品的用户数 办公 Agent 功能本身的日活
付费席位 已购买的授权数量 实际活跃人数或任务完成率
提示词量份额 调查范围内各产品占用的提示词数量 企业采购份额或办公用户份额
企业客户数、ARR 客户覆盖或经常性收入规模 日活、用户份额和单任务效果

因此，下面分别展示调查数据和厂商披露数据。未找到的办公 Agent 日活保留为空，不根据其他指标推算。

市场格局：两种可观察的口径

美国企业的平台渗透率

Morning Consult 在 2026 年 7 月 21 日至 24 日调查了美国企业决策者。以下比例表示平台在企业中已获批准或正在使用。全规模企业样本主要包含小企业。调查结果与方法

平台 各规模企业样本中的比例
Google Gemini 55%
ChatGPT 48%
Microsoft Copilot 45%

在另外统计的大型企业样本中，Microsoft Copilot 在 1,000 至 4,999 人企业的比例为 82%，在 5,000 人以上企业的比例为 73%。三个样本分别报告。一个企业可以批准多个平台，获批准也不代表所有员工都在使用。这些数字不能作为可相加的市场份额。

美国 AI 助手的提示词量

Comscore 的调查显示，2026 年 6 月，ChatGPT 占其统计范围内 AI 提示词总量的 50%，Gemini 为 30%，Claude 为 11%。这是一项 AI 助手使用量观察，包含通用场景。它不能用来计算办公 Agent 的用户份额或企业支出份额。Comscore 报告

产品如何形成差异化

ChatGPT Work：从通用入口进入跨应用工作

ChatGPT Work 利用 ChatGPT 的用户入口，将研究、分析和多步骤任务委派整合到一个体验中。它可以连接应用和文件，并生成文档、表格或演示材料。用户可以跟踪任务进展，并在需要时审阅重要操作。OpenAI Docs：Work 入门

它的策略是以通用用户基础进入工作场景，再通过工作区、连接器和权限管理进入企业。对于需要跨多个工具收集信息、分析数据和制作交付物的团队，这种入口有吸引力。

限制在于：企业内部数据和操作需要单独配置连接权限。ChatGPT 整体用户规模不能证明 Work 的企业使用深度。部署时还需要审查敏感数据的访问和处理方式。

Microsoft 365 Copilot：利用现有办公套件

Microsoft 将 Copilot 放进 Word、Excel、PowerPoint、Outlook 和 Teams 等现有工作入口。Copilot Cowork 等能力向多步骤任务扩展。企业还可以通过相关平台配置和管理 Agent。Microsoft 财报

它的策略依赖现有的办公软件部署、企业身份体系和采购关系。员工不必先迁移到新的文档系统。部分场景也允许在 OpenAI 和 Claude 模型之间选择。PowerPoint 模型选择

对于深度使用 Microsoft 365 的企业，现有入口和权限体系有利于推广。实际效果仍取决于文档质量、权限配置、员工使用频率和具体功能的可用性。

Google Gemini：Workspace 与通用 Gemini 入口

Google 将 Gemini 集成到 Gmail、Docs、Sheets、Slides 和 Drive，也提供独立 Gemini App。Google 在 2026 年 10 月介绍了面向工作的 Gemini agent，强调连接业务上下文、选择模型和使用工具完成任务。Workspace 功能 · Gemini agent

它的策略结合了 Workspace 的协作入口和 Gemini App 的用户覆盖。搜索、多模态处理和内容生成可以服务文档、邮件及资料整理等工作。对以 Google Workspace 为中心的团队，接入路径较直接。

Gemini App 月活只说明通用应用的覆盖规模。企业需要分别确认 Workspace 功能、模型选择和所在地区的开放情况。

Claude Cowork：委派长任务与专业流程

Claude Cowork 面向跨多个文件、应用或步骤的工作。用户可以给出目标，再审阅 Agent 返回的成果。Anthropic 使用连接器、Skills 和插件组织专业工作流程。金融服务模板还组合了领域说明、数据连接和子 Agent。Claude 企业资料 · 金融 Agent

它的策略是通过 MCP 和合作伙伴连接现有系统，再将专业经验打包为可复用流程。复杂研究、多个文件的分析和专业材料准备是值得试验的场景。

公开资料不足以判断 Cowork 的独立日活或市场份额。模板也不能替代企业对数据权限、结论正确性和审批步骤的验证。

Notion Custom Agents：依托团队知识库

Notion 以页面、数据库和项目空间承载团队知识。Custom Agents 可以使用工作区内容，连接 Slack 等服务，并共享给团队成员。Notion Custom Agents

它的策略是让 Agent 靠近团队已有的知识和流程，再用共享 Agent 沉淀重复任务。模型供应商可以选择，也可以使用自动模式。

这种方式适合已经把项目和知识维护在 Notion 的团队。最终效果依赖内容是否完整、权限是否准确，以及外部连接器是否覆盖实际工作。

Glean：连接企业知识与权限

Glean 从企业搜索发展为包含 Assistant 和 Agents 的平台。它连接不同的企业系统，为查询和任务提供企业知识上下文。Glean 产品介绍

它的策略是建立跨系统的检索和权限能力，减少员工在多个应用中寻找信息的成本。Glean 也提供多模型选择，让企业按任务和管理策略选择模型。

它适合知识分散在多个 SaaS 或内部系统的组织。试点时需要验证连接器覆盖、索引更新、权限同步和检索结果质量。收入规模不能直接说明活跃用户数。

Salesforce Agentforce：围绕 CRM 和业务流程

Agentforce 面向销售、客户服务和 IT 服务等业务流程。它将 Agent 连接到 Salesforce 中的业务数据和操作。该产品与通用办公助手有交集，范围也延伸到面向客户的服务自动化。Agentforce 指标

它的策略是依托 CRM 数据、业务对象和工作流程。客服等高频流程可以围绕处理量、解决率和人工交接等指标评估效果。Agentforce 也提供托管模型和第三方模型选项。

如果企业已有 Salesforce 流程和数据，这条路径值得评估。项目效果仍取决于数据准备、系统集成和流程改造。

竞争集中在哪些层面

竞争点 代表性路线 评估问题
用户入口 Microsoft、Google、OpenAI 员工能否在日常使用的界面启动任务
工作上下文 Microsoft、Google、Notion、Glean Agent 能否找到有权限访问的相关信息
多步骤执行 ChatGPT Work、Claude Cowork、Gemini agent Agent 能否跨应用完成任务并返回可审阅结果
专业流程 Claude、Notion、Salesforce 团队能否复用规则、模板和业务操作
权限与治理 Microsoft、Glean、Salesforce 等 企业能否控制访问、审批、审计和模型使用

基于上述资料，一个合理判断是：工作上下文、受控的执行能力和可复用流程，将持续影响办公 Agent 的竞争力。模型需要正确的信息才能完成任务。Agent 也需要经过授权的操作能力，才能把结论转化为业务动作。拥有数据入口并不自动证明任务完成率，仍需要在真实工作中验证。

企业如何开展试点

先从现有工作平台出发。Microsoft 365 用户可以先测试 Copilot。Google Workspace 用户可以测试 Gemini。Notion 用户可以检查 Custom Agents 对现有知识库和流程的覆盖。知识分散的企业可以评估 Glean。客服和销售自动化可以评估 Agentforce。跨应用研究与产物制作可以比较 ChatGPT Work 和 Claude Cowork。

选择同一批真实任务进行对照，避免只比较演示效果。试点至少应记录：

  1. 任务完成率：最终结果是否满足可预先定义的验收条件。
  2. 人工修改量：员工需要花多少时间核对和修正。
  3. 可追溯性：能否定位数据来源和关键操作。
  4. 权限与错误操作：是否出现越权访问、错误写入或未经批准的外部动作。
  5. 耗时与成本：从提交任务到可用结果的时间，以及许可证、调用和维护成本。

产品规模有助于判断市场覆盖。企业采购还需要结合自己的数据、权限和工作流程，验证 Agent 能否稳定交付。

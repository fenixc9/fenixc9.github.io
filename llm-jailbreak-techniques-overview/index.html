大模型越狱技术全景：14 类破甲方案的实现与防御

越狱攻击（jailbreak，中文常称破甲）利用安全对齐的两个失败模式。第一个是竞争目标：模型的指令跟随目标和安全目标互相冲突。第二个是泛化不匹配：模型的预训练能力覆盖很广，但安全训练覆盖很窄。

Wei 等人 2023 年的论文用这两个失败模式构造攻击。这些攻击在评估集上成功率超过 96%，在其中一批精选红队 prompt 上达到 100%。这个结果说明，越狱来自当前训练方式，而不是模型的偶发缺陷。

下面按攻击者需要的权限，把 14 类主流方案分成六组。每组给出实现方式、实测数据和对应防御。文中的数据来自各方案原始论文和 2026 年的综述统计，核对日期为 2026 年 10 月。

一、模型级攻击：需要权重或微调权限

这一组攻击直接改动模型参数。模型在接收任何 prompt 之前就没有护栏，因此它能绕过全部提示层防御。

1.1 权重消融（Abliteration）

Abliteration 由 FailSpy 命名，做法来自 Arditi 等人的发现：模型的拒绝行为由残差流中的一个方向向量介导。攻击分三步。第一步，用无害和有害两组 prompt 跑模型，记录每一层的激活值。第二步，比较两组激活值的差异，提取拒绝方向。第三步，把权重沿这个方向做正交投影。

整个过程不需要重新训练。处理后的模型失去拒绝能力，但各项基准测试出现性能下降。原因是拒绝机制和模型的指令理解、推理能力有耦合。为了弥补损失，可以用 DPO 做一轮轻量偏好对齐。Maxime Labonne 用这个方法做出了 NeuralDaredevil-8B。

Cracken 团队 2025 年的研究修正了「拒绝是单一方向」的假设。在万亿参数级模型上，拒绝行为按领域分开编码。他们只移除了网络安全领域的拒绝，保留了其他安全边界。

1.2 去审查微调

去审查微调是更直接的做法。开发者用无拒绝数据做一轮监督微调，得到 “-Uncensored” 后缀的模型。HuggingFace 上有大量这类模型。量化时使用 imatrix 可以减少权重损失。这个方案只对开放权重模型有效，对 Claude、GPT 这类闭源 API 无效。

1.3 微调越狱

Qi 等人 2023 年的论文（ICLR 2025）给出一个更低的门槛。只用 10 到 100 条有害样本、训练 5 个 epoch，就能让模型整体偏离对齐。偏离是全局的：模型对各种有害请求都放行，不只是对训练样本放行。

论文还有一个意外发现。即使用户提交完全良性的微调数据，安全边界也会下降。这意味着提供微调 API 的厂商面临真实攻击面，而且攻击者不需要恶意意图就能触发。

二、提示级白盒攻击

这一组攻击需要模型的梯度或部分内部信息。攻击者通过搜索找到有效的 prompt。

2.1 GCG 对抗后缀

GCG（Greedy Coordinate Gradient）由 Zou 等人在 2023 年提出。攻击者对目标回复的损失求梯度，用贪婪坐标梯度搜索一段无意义的后缀，把后缀接到有害请求后面。模型随后输出肯定式回复。

这段后缀是 token 序列，不是自然语言。在开源模型上搜出的后缀可以迁移到其他模型，包括闭源 API。

TACL 2025 的研究解释了迁移的原因。越通用的后缀，对模型注意力的劫持越强。这种劫持强度在不生成任何 token 的情况下就能测得。后缀劫持的是注意力分配机制，不是记忆的内容。

GCG 有一个明显弱点。在统一算力轴上的对比研究（arXiv 2603.11149，2026 年 3 月）显示，GCG 的天花板最低、增长最慢。梯度优化的是 token 空间，容易触发表层违规。模型被判违规，但回复不切题，相关性得分只有 1.46。

2.2 AutoDAN 遗传算法

AutoDAN（Liu 等人，2024 年）在人工越狱模板的基础上做演化。它从 DAN 系列模板出发，用分层遗传算法生成新的 prompt。名字的含义是「自动生成 DAN 系列风格的越狱 prompt」。

AutoDAN 的产物保持人类可读。它解决了 GCG 的两个问题：后缀是乱码，会被困惑度过滤抓到；后缀对特定模型过拟合。在算力轴上，AutoDAN 的改善速度更平缓。

三、提示级黑盒攻击

这一组攻击只需要 API 访问权。它是实际攻击中最常见的路径。

3.1 PAIR 与 TAP 迭代改写

PAIR（Chao 等人，2023 年）用一个攻击 LLM 迭代改写越狱 prompt。攻击 LLM 同时扮演用户和攻击者。它读取目标模型的拒绝回复，改写出语义相同但更隐蔽的新 prompt，循环直到成功。论文的实验结果是平均不到 20 次查询攻破 GPT-4 和 Claude 级模型。

TAP（Mehrotra 等人，2024 年）把迭代扩展成带剪枝的树搜索。它用 Vicuna-13B 作为攻击模型、GPT-4 作为评判，在 GPT-3.5、GPT-4、Claude-3、Gemini-Pro 等模型上评估。TAP 在多项指标上超过 PAIR 和 GCG。

ACL 2026 的综述给出一个统计结果：搜索类攻击与迭代交互显著正相关（r=0.57）。原因是并行搜索的算力开销大，还会撞上 API 限流。PAIR 的浅搜索深度加中等搜索空间是实践上的平衡点。

3.2 Best-of-N 采样

Best-of-N（Hughes 等人，2024 年）对同一个有害 prompt 生成多个变体。文本侧用随机大写、字符打乱，图像侧用无意义扰动。攻击者采样 N 次，直到出现一个有害输出。

这个方案利用输入方差和采样随机性，与模型的具体弱点无关。拒绝本身是随机的：同一语义的 prompt，有的变体被拒绝，有的放行。采样次数足够多，总有一个通过。

实测数据显示它的效果不弱。在算力轴对比中，Best-of-N 的相关性得分天花板是 5.38，超过 PAIR 的 3.86。原因是它只做表面扰动，原始请求的语义完整保留，引出的回复始终切题。成功所需的样本数随 N 呈幂律分布，因此可以外推。

四、上下文类攻击

这一组攻击利用对话的累积性和上下文窗口。

4.1 Crescendo 多轮升级

Crescendo（Russinovich 等人，Microsoft）从无害问题开始。每一轮基于模型已经给出的内容升级提问。典型路径是：无害主题、略敏感话题、跨主题连结、临近目标、最终请求。每一步都合理延续上一步。

这个方案攻破了 ChatGPT、Gemini Advanced、Anthropic 和 LLaMA-2。表征层面的研究给出解释：模型把 Crescendo 输入表征为更良性，而不是有害。多轮语境平滑地移动了向量空间。

Crescendo 的底层弱点是注意力稀释和前缀依赖。长上下文稀释有害信号的注意力占比。自回归生成不回溯评估，每一轮的服从都成为下一轮的合法性来源。Crescendo 与 GCG 后缀组合后，在 GPT-4 和 Claude 上的成功率接近 100%。

4.2 Many-shot 长上下文

Many-shot 越狱（Anthropic，2024 年）在单条 prompt 内伪造大量「用户-AI」假对话。每个假对话里，AI 都顺从地回答有害问题。最后接上真正的目标问题。实验最多用了 256 个 shot。

只放少量假对话时，安全训练仍会触发。shot 数超过一定阈值后，模型转而模仿假对话，忽略安全对齐。这里利用的是 in-context learning。上下文窗口从 2023 年初的 4K token 增长到 1M 以上，直接放大了这类攻击。

Many-shot 与多轮攻击同属上下文累积类，但它不依赖真实交互。多轮审核类防御对它无效。

五、表征变换类攻击

这一组攻击把有害请求换成另一种表征，绕开文本侧的安全训练。

5.1 Base64 与编码混淆

Base64 越狱是「泛化不匹配」最尖锐的例子。攻击者用 Base64 编码有害请求。模型在预训练中学会了跟随 Base64 指令（能力泛化广），但安全训练数据里没有这种形态（安全泛化窄）。输入远超出分布，拒绝机制不激活。

消融实验发现两点。编码输入比编码输出更重要。两者的组合最强。编码输出有效是因为部分解码的前缀引导了拒绝行为，这个性质与前缀注入共享。

原论文的数据：Base64 单独在 GPT-4 上成功率 0.34，在 Claude v1.3 上 0.38。组合攻击达到 0.94。JailbreakRadar 的跨模型评估显示，Base64 单用对现代模型平均成功率只有 0.16，组合后才是主力。

同一谱系还有 ROT13、leetspeak、摩斯码、Hex、payload splitting 等方案。USENIX Security 2026 的论文给出结论：密码类 prompt 无法被通用封锁。混淆方案的空间无法枚举。

5.2 多模态视觉越狱

FigStep（清华，AAAI 2025）把违禁指令转成排版渲染的图片。文本侧只附带一个无害问题。模型的视觉通道读出图片里的文字并执行，但拒绝训练从未覆盖「图像内文字携带违禁指令」的形态。

在 6 个主流开源视觉语言模型上，FigStep 的平均成功率是 82.5%。它还能引出模型在后续文本回复中生成有害内容。

这个结果说明安全对齐在模态之间不泛化。Best-of-N 的跨模态实验也证明视觉模态的安全对齐弱于文本。

六、格式与人格类攻击

这一组攻击利用模型的指令跟随倾向。

6.1 DAN 与角色扮演

DAN（Do Anything Now）出现于 2022 年 12 月，是 ChatGPT 发布数周后的最早越狱。它用冗长的角色描述让模型扮演一个没有限制的助手。同族还有 AIM、dev_mode_v2、奶奶绕过等。

这一组利用竞争目标。模型被训练成乐于服从指令的助手，角色扮演把这个训练成果变成攻击向量。

人工 prompt 的有效性高度依赖模型。Wei 等人的数据显示，AIM 在 GPT-4 上成功率 0.75，在 Claude v1.3 上为 0.00。这个差异是人工方法被自动化方法取代的原因之一。今天这些 prompt 主要作为组合攻击的组件和 AutoDAN 的初始化模板。

6.2 Policy Puppetry 与 Skeleton Key

Policy Puppetry（HiddenLayer，2025 年）把有害请求伪装成高信任的格式：系统策略文件、开发者指令、交互配置。它用 <interaction-config>、<Blocked-string> 这类 XML 标记模仿内部过滤器，制造「拒绝才违反策略」的错觉。这个方案在 GPT-4、Claude、Gemini 和开源模型上通用。

Skeleton Key（Microsoft，2024 年）用多轮方式实现同类效果。它先让模型承认自己的系统指令存在，再要求模型把用户指令设为最高优先级。之后模型对所有请求放行。Microsoft 在 Meta Llama 等多个模型上验证了该攻击。

这一类攻击的弱点是模型无法可靠区分真系统指令和「长得像系统指令」的用户输入。

七、相邻攻击面：间接提示注入

间接提示注入攻击的目标是系统的检索和指令通道。攻击者把隐藏指令种在外部语料中：网页、邮件、工单、帮助文档。AI 系统检索到它时执行指令，全程不需要直接交互。

实证数据说明它很普遍。GPT-4 在一天 CVE 利用基准上达到 87%。HPTSA 多智能体框架把这个结果扩展到零日漏洞。有独立研究者对六个真实 AI 系统跑了约 1 万次注入攻击，结论是「把一行秘密指令塞进 AI 稍后读取的文档，它经常会直接执行」。

真实案例是 EchoLeak（CVE-2025-32711，严重等级 9.3）。受害者让 Microsoft 365 Copilot 总结邮件，检索到的邮件含隐藏指令，Copilot 执行指令并通过图片 markdown 把数据外传。

下面这张表对比越狱和间接提示注入。

维度 越狱 间接提示注入
攻击对象 模型的拒绝机制 系统的检索和指令通道
交互方式 直接对话 经外部数据源，无需交互
攻击者位置 对话方 语料提供方
典型后果 生成有害内容 执行指令、外传数据

两者在实战中经常组合。注入的内容本身可以是一条越狱 prompt。

八、防御的对应关系

不同的攻击类别对应不同的防御责任。

攻击类别 防御责任
模型级（消融、微调越狱） 发布链路审计、微调输出回归测试
白盒搜索（GCG） 困惑度过滤、输入规范化、输出分类
遗传搜索（AutoDAN） 语义层和意图层检测，困惑度过滤无效
语义迭代（PAIR/TAP） 会话内迭代探测的行为分析
采样（Best-of-N） 限流、异常请求检测、输出审核
多轮升级（Crescendo） 整个会话历史的升级轨迹分析
长上下文（Many-shot） 假对话模式检测、上下文清洗
编码变换（Base64） 解码后审核、拦截编码输出
多模态（FigStep） 图像 OCR 加安全分类、跨模态对齐
格式人格（DAN、Policy Puppetry） 指令与用户输入分层、结构化输入校验
间接注入 检索层权限门控、指令与数据边界隔离

有两条规律贯穿全部方案。第一，多数攻击利用的都是「安全训练覆盖窄于能力训练」这个缺口。逐个修补缺口永远落后。第二，2026 年的独立红队测试显示，前沿模型拒约 88% 到 94% 的攻击意图，剩下 6% 到 12% 被攻破。这部分就是实际攻击面。

不预测涨跌也能给期权定价：图解 Black-Scholes 方程

在 1973 年 Fischer Black、Myron Scholes 和 Robert Merton 提出期权定价理论之前，金融界普遍认为：要给一份看涨期权定价，必须先预测标的股票未来的预期收益率 μ\muμ。问题在于，几乎没人能稳定预测股价涨跌。

Black-Scholes 方程最反直觉的结论在于——标的资产的真实预期收益率 μ\muμ 根本不会出现在定价公式里。只要市场允许动态对冲且不存在无风险套利，期权价格就只取决于现价、行权价、剩余期限、无风险利率和波动率。本文从随机过程出发，逐步拆解这套方程的推导过程、物理类比、解析解含义、希腊字母风险度量以及它在真实市场中的边界。

核心思路：用动态对冲消去随机性

假设现在有一只股票现价 SSS，以及一份以它为标的、到期日为 TTT、行权价为 KKK 的欧式看涨期权，当前价格记为 V(S,t)V(S, t)V(S,t)。

如果只持有期权，盈亏会随着股价随机剧烈波动；但如果买入 1 份期权的同时，卖空 Δ\DeltaΔ 股标的股票，当股票小幅上涨时，期权赚钱、股票空头亏钱；当股票小幅下跌时，期权亏钱、股票空头赚钱。只要在每一瞬间把股数 Δ\DeltaΔ 精准选为期权价格对股价的斜率 ∂V/∂S\partial V / \partial S∂V/∂S，两者的一阶随机涨跌就会完全抵消。

这样构造出的投资组合在极短时间 dtdtdt 内没有随机风险。根据无套利原则，任何无风险资产的瞬时收益率都必须等于无风险利率 rrr——否则套利者就可以借钱买入（或卖空）这个组合白赚差价。正是这个约束，把未知的期权价格函数 V(S,t)V(S, t)V(S,t) 牢牢锁死在一个偏微分方程里。

模型的六项理想假设

标准 Black-Scholes 方程建立在以下理想化前提之上：

  1. 标的服从几何布朗运动（GBM）：资产价格连续变化，不存在跳空缺口，对数收益率服从正态分布。
  2. 参数恒定：标的波动率 σ\sigmaσ 与无风险利率 rrr 在期权存续期内保持为常数。
  3. 无摩擦市场：无交易佣金与税收，资产可无限细分，允许无限制卖空且资金可按无风险利率 rrr 自由借贷。
  4. 连续动态对冲：交易者可以在连续时间上随时调整对冲比例 Δ\DeltaΔ。
  5. 存续期内无分红：若存在连续股息率 qqq，可将模型推广为 Black-Scholes-Merton 形式，将公式中的 SSS 替换为 Se−q(T−t)Se^{-q(T-t)}Se−q(T−t)。
  6. 欧式行权：期权只能在到期日 TTT 行权，不能提前行权。

热传导类比与闭式解析解

Black-Scholes 方程本身适用于所有欧式衍生品，真正区分看涨、看跌或其他收益结构的，是到期日 TTT 的终端边界条件：

  • 欧式看涨期权（Call）：C(S,T)=max⁡(S−K,0)C(S, T) = \max(S - K, 0)C(S,T)=max(S−K,0)
  • 欧式看跌期权（Put）：P(S,T)=max⁡(K−S,0)P(S, T) = \max(K - S, 0)P(S,T)=max(K−S,0)

30 行标准库 Python 代码验证

仅用 Python 标准库 math 就能复现文中所有计算，并直接验证 Black-Scholes PDE 的残差为零：

import math


def norm_cdf(x: float) -> float:
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))


def norm_pdf(x: float) -> float:
    return math.exp(-0.5 * x * x) / math.sqrt(2.0 * math.pi)


def black_scholes_call(S: float, K: float, T: float, r: float, sigma: float) -> dict:
    sqrt_t = math.sqrt(T)
    d1 = (math.log(S / K) + (r + 0.5 * sigma * sigma) * T) / (sigma * sqrt_t)
    d2 = d1 - sigma * sqrt_t
    df = math.exp(-r * T)

    price = S * norm_cdf(d1) - K * df * norm_cdf(d2)
    delta = norm_cdf(d1)
    gamma = norm_pdf(d1) / (S * sigma * sqrt_t)
    theta_annual = -(S * norm_pdf(d1) * sigma) / (2.0 * sqrt_t) - r * K * df * norm_cdf(d2)
    vega_1pct = S * norm_pdf(d1) * sqrt_t / 100.0
    pde_residual = theta_annual + 0.5 * sigma * sigma * S * S * gamma + r * (S * delta - price)

    return {
        "price": price,
        "delta": delta,
        "gamma": gamma,
        "theta_daily": theta_annual / 365.0,
        "vega_1pct": vega_1pct,
        "nd2": norm_cdf(d2),
        "pde_residual": pde_residual,
    }


res = black_scholes_call(S=100, K=100, T=0.5, r=0.05, sigma=0.25)
for k, v in res.items():
    print(f"{k}: {v:.6f}")

现实世界的局限与后续演进

Black-Scholes 方程在 1997 年为 Scholes 与 Merton 赢得了诺贝尔经济学奖（Black 于 1995 年去世），但真实市场几乎在每一条假设上都会偏离它：

  1. 波动率微笑与偏斜（Volatility Smile / Skew）：模型假设同一标的、同一到期日的所有行权价共享同一个常数 σ\sigmaσ。然而把真实市场价格代入公式反推出来的隐含波动率（Implied Volatility, IV），在汇率市场常呈 U 形“微笑”，在股票市场常呈左高右低的“偏斜”——因为投资者更恐惧崩盘，愿意为深度虚值看跌期权支付更高溢价。因此在实盘里，交易员并不是用 BS 公式“算价格”，而是把它当作把价格翻译成隐含波动率的通用报价语言。
  2. 肥尾与价格跳空：真实收益率存在尖峰肥尾和突发跳空（例如财报发布、黑天鹅事件），导致连续 Delta 对冲在跳空瞬间失效。针对这类风险，后续发展出了 Merton 跳跃扩散模型。
  3. 波动率本身在随机波动：市场波动具有明显的“聚集效应”，且往往在下跌时骤升。现代量化机构广泛采用 Heston 随机波动率模型、SABR 模型 和 Dupire 局部波动率模型来拟合完整的波动率曲面。
  4. 美式期权与路径依赖衍生品：允许提前行权的美式期权或障碍、亚式等奇异期权大多没有闭式解，工程上通常用二叉树（CRR）、有限差分法（直接数值求解 BS PDE）或蒙特卡洛模拟来完成定价。

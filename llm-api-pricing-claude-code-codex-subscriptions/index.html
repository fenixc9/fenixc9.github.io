按自己的用量估算

对自建应用，把 API 赠额从预计按量账单中扣除。若把整笔月费归入 API 成本，每消费 1 美元官价额度的实际成本为：

实际成本倍数=订阅月费实际消耗的 API 赠额\text{实际成本倍数} = \frac{\text{订阅月费}}{\text{实际消耗的 API 赠额}}实际成本倍数=实际消耗的 API 赠额订阅月费​

月费 100 美元且消费 25 美元 API 赠额时，每消费 1 美元官价额度要花 4 美元。工具内的价值可以用同一周的实际调用日志单独计算。随后用各自模型的 API 官价折算，并对照完成的任务数。这样可以把订阅使用率、模型消耗和交付结果放在同一份预算里。
